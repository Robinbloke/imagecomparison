# imagecomparison
A python based image comparison tool<br>
<br>
No documentation, because life is too short.<br>
Created using multiple iterations with cursor to get a quick test app.<br>
Free to use and distribute, go for your life, just don't say you made it.<br>
<br>
Install<br>
<br>
Verified on Python 3.12.3 , anything else you take your chances.<br>
Tested on Ubuntu 24.04 LTS, other platforms may vary.<br>
<br>
I recommend using uv to install the requirements:<br>
<br>
uv venv --python 3.12 .venv<br>
source .venv/bin/activate<br>
uv pip install -r requirements.txt<br>
<br>
Then you can run with<br>
<br>
python3 image_duplicate_finder.py<br>
<br>
Good luck.
