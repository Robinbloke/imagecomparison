# imagecomparison
A python based image comparison tool

No documentation, because life is too short
Created using multiple iterations with cursor to get a quick test app
Free to use and distribute, go for your life, just don't say you made it.

Install

Verified on Python 3.12.3 , anything else you take your chances.
Tested on Ubuntu 24.04 LTS, other platforms may vary

I recommend using uv to install the requirements:

uv venv --python 3.11 .venv
source .venv/bin/activate
uv pip install -r requirements.txt

Then you can run with

python3 image_duplicate_finder.py
